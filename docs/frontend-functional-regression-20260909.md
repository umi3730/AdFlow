## CSV 导出的边界

服务端 CSV 接口验证通过：HTTP 200，`text/csv; charset=utf-8`，带 attachment 文件名；全天 24 个小时桶，计数和金额与 JSON 报表一致。

但语义点击和辅助功能元素点击后，内置浏览器均未捕获下载事件，也没有在默认 Downloads 目录找到对应文件。页面未报错。**浏览器文件下载落地仍未确认，不能将这一项标记为端到端通过**；此次没有据此修改下载实现。

[CSV 样本](verification/frontend-functional-regression/final-report.csv)由独立 HTTP 读取保存，用于数据核对，不代表浏览器下载成功。

日期测试中，自动填充值未触发 React 日期状态更新；改用真实键盘输入后，待查询状态和范围校验均正常。
