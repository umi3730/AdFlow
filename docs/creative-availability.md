# 素材启用/禁用与本地选择

- 计划：ACTIVE → 暂停 → PAUSED → 恢复 → ACTIVE，原有入口保留。
- 素材页的计划下拉采用明确选择，不再用空值回退到第一项；可清除选择，已选计划在列表刷新/排序变化时保持不变。切换计划清空待添加预览，并用请求序号忽略旧素材列表响应；读取错误单独展示，不冒充“无素材”。
- 素材：ACTIVE → 禁用 → DISABLED → 重新启用 → ACTIVE；每次合法变更递增 revision，保留现有乐观锁。
- 启用/禁用会核对素材归属与父计划是否存在。已删除的素材或计划返回 404，已启用素材重复启用返回 422，不能借启用恢复删除记录。
- 权限沿用 operator/admin，enable 操作记入现有审计中间件。
- 启用素材不会改变父计划状态；进入决策候选池仍须计划投放中、时间匹配及有效素材，候选快照有默认约 5 秒 TTL。
- 素材管理页面目前只能从本地 19 张预设中选择，移除图片 URL 输入框，并在提交时校验预设 ID。没有新增文件上传功能；落地页地址是点击目标，仍可单独设置。
- 素材库放在右侧，接收区和添加表单放在左侧素材列表上方。拖入高亮、松开预选，左侧确认后才添加；也保留点击/键盘选择。拖放仅接受已登记素材 ID 与专用 MIME 类型，拒绝文件、外部链接和未知 ID，不直接创建或发布。
- 添加成功后清空待添加素材、右侧选中标记和旧拖放提示，标题继续自动编号；已保存列表不清空。失败保留待添加内容，空选择不能重复提交。
- 首次进入、重新进入以及下拉切换计划时，待添加素材均为空，不自动选择第一张图片。预览状态按计划与选择 ID 重置；已保存的素材列表不受影响。
- 后端通用素材接口继续接受合法 HTTP/HTTPS URL，兼容既有记录和其他调用端；此处的“本地选”指管理页面的录入流程，不是新增后端 URL 白名单策略。
- 本地路径提交前转为当前前端 origin 下的绝对 URL，后端不读取用户任意磁盘路径。已有外链素材不迁移、不删除。
