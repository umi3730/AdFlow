# 演示流程与状态恢复优化 · 2026-09-10

本轮围绕批量测试上手、计量结果解释和页面恢复做小范围前端改进。复用现有组件与 Go API，没有新增后端接口、数据表、依赖或任务调度系统。

## 行为变化

- 批量页保留现有用例入口，默认折叠自定义用户池与高级运行参数。时间限制始终显示摘要；生成、选择用户和配置校验仍按原有逻辑执行。开始运行前不展示整屏零指标。
- 原“已完成”改为“请求已结束”，明确事件受理与最终计量的区别。
- 记录最近 20 轮中已收到成功响应的原始事件 ID，包括后续步骤失败之前已经接收的事件。点击“核对统计”后逐条读取现有请求追踪接口，只以对应事件的 `processedAt` 证明计量完成。
- 核对区展示已计量、尚未确认、需处理与查询失败的数量。不会拿已发布状态、报表总数或其他批次事件代替本次证明；超过 20 轮不声称已核对整批。每次点击最多读取 20 个请求，每个读取最多等待 3 秒，不自动轮询或重放。离开页面或开始新批次时取消旧查询，新批次不继承旧确认结果。
- 工作区、计划搜索/广告位/状态、已应用的报表日期/计划/粒度写入 URL。导航与报表查询进入浏览器历史，计划输入筛选替换当前记录，避免输入一个字就新增一条历史。保留 URL 中的其他参数和锚点。
- 非法页面使用总览；非法报表日期或粒度回退默认查询。报表未提交的筛选仍保持原有待查询行为。页面角色校验继续生效。

## 范围

继续采用现有本地演示流程。刷新恢复页面和已应用筛选，不恢复或重启模拟任务；临时用户、未提交表单与模拟结果仍在当前会话内存中。其他体验建议本轮未扩展。

验证：145 项前端测试、类型检查、lint、格式检查和生产构建通过；18 项完整浏览器回归通过，最终代码的 8 项定向复查通过。覆盖桌面与 390px 窄屏、URL 刷新与历史恢复、真实计量核对、新批次清除旧确认、全局停止。
