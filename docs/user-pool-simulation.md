# 用户池固定并发模拟

## 当前行为（2026-09-07）

只保留固定并发：启动时填充并发槽，每完成一轮补一轮。每轮包括决策，以及所选的曝光、点击、转化回传。删除匀速调度与时隙跳过指标。

默认并发 10、最大 1000 轮、最长派发 30 秒、单轮超时 5 秒。硬上限为 100 个用户、100 个并发轮次、3000 轮、120 秒；轮数或时长先到即停止补发。补位经短定时器让出事件循环，无无界等待队列。目标并发不是浏览器连接数或后端 goroutine 数；浏览器、网络和后端准入共同影响实测结果。后端默认在途决策上限 256，此次不改变后端准入配置。

## 用户池

- 先选择用户，再配置广告位与运行参数。临时池与已保存用户各自保存画像和勾选，切换来源不清空；刷新保存用户只移除已经不存在的选择。
- 临时画像只在浏览器内存中生成，不向画像接口 PUT。支持样本种子和换一批：同种子、同人数得到相同画像，每种属性独立采样，避免设备和兴趣按序号固定绑定。
- 页面 ID 为 user-0001 到 user-0100；服务端通过 runId 和用户 ID 派生隔离身份。临时运行每次使用新身份，用户频控重新计算，计划预算仍累计。已保存用户沿用原身份与频控。
- 保存用户最多读取前 100 人，刷新后保留仍有效的选择。两种来源不混选，同名显示 ID 不代表同一身份。
- 站内切页保留用户池和运行；刷新、退出登录清空页面状态。浏览器进入后台会取消在途请求。
- 临时入口仅在 local/test 环境注册，要求管理员和 loopback；临时与正式模式共用准入、候选、决策、预算、事件链路，临时模式跳过画像库及画像缓存读取。

## 运行控制

- 开始前展示人数和当前广告位的投放中计划数。没有计划时明确提示可能全未命中，仍允许测试无广告场景；没有用户不能开始。
- 达到轮数或时长：停止补发，等待已经发出的轮次结束或超时。
- 结束并等待：主动停止补发，保留已发出的轮次，结果标记 manual_drain。
- 立即停止：AbortController 取消所有在途轮次，也可在等待结束期间使用。取消不回滚后端已接受的请求。
- 运行中参数锁定，操作条保持可见；启动后滚动到结果。站内其他页面保留停止入口和最多 15 秒的结束后统计刷新。

## 结果和导出

主结果区展示已发决策、命中、未命中、曝光、点击、转化；No-Ad 会明确显示主要原因。流程正常完成包含 No-Ad，不等同于广告命中。

正常完成 + 失败 + 取消 + 在途 = 已发轮次。命中率分母为有效决策响应；曝光失败可能是已命中但流程失败。完成轮次/秒使用正常完成和失败轮数除以实际用时，HTTP 调用总数包含所有已尝试的事件请求。

P50/P95/P99 是浏览器整轮耗时，含网络、等待、失败/超时和所选回传，排除手动取消。分位数共用一次排序并按样本量缓存。曝光后可开启概率点击、转化，转化金额以整数分生成；它是模拟金额，不是真实收入。已接收的事件在 Kafka 模式下可能尚未聚合。

JSON 报告 schemaVersion 为 2，保存实际运行配置、开始时间、来源、生成种子、所选画像与计划快照和统计。修改下一轮配置不改写上一轮结果。删除旧 rate/skippedBusy/skippedLate 字段；当前不支持旧模式报告回放。

## 验证范围

- 注入时钟测试覆盖 100 并发、257 轮的精确上限、时长排空、主动排空与强制取消、超时、完整事件顺序、报告隔离、样本种子及刷新选择保留。
- 本地集成脚本 tests/user-pool-simulation-smoke.mjs 使用独立测试计划、4 位临时用户，以并发 3 完成 10 轮决策→曝光→点击→转化，40 次 HTTP 调用，失败为 0；与后端转化指标一致，画像目录前后不变。仅清理脚本自己创建的计划。
- 浏览器以目标并发 100 运行 257 轮，无候选场景全部正常完成，峰值在途轮次 100；此结果只验证调度及 No-Ad 链路，不是完整投放吞吐基准。
- 可描述：实现固定并发广告业务模拟器，支持最多 100 个在途轮次、确定性用户画像生成、串行事件回传、可取消请求与 P50/P95/P99 分析，并通过有界并发与端到端回归验证。
- 若要写后端 QPS/延迟指标，使用仓库已有 k6 基线，保留机器、数据规模、准入配置和持续时间。不能用浏览器并发上限替代实测承载能力。
