# Agent 规则助手

## 当前交互（2026-09-04 更新）

1. 在 Agent 页面描述需求并生成规则。
2. 直接修改日预算、单次曝光成本、每人每日曝光上限；校验通过后点击「创建计划」。
3. 跳转到广告计划页，聚焦创建表单。自动填写测试计划名与默认广告位，同时带入已修改的规则与费用。
4. 点击「创建草稿并确认规则」后才创建后端 DRAFT 计划，自动打开预填规则的编辑器；最后人工确认发布。
5. Agent 不再提供选择、套用或覆盖已有计划的入口。广告计划页原有的常规编辑功能仍保留。

## 数据与安全边界

- 跳转只转移表单数据，不创建或发布计划。只有点击广告计划页的创建按钮才调用创建接口。
- 费用先校验再转移，金额按整数分处理；转移的是用户修改后的值，不是原始模型默认值。
- 待创建草稿保留在控制台状态中；创建后按返回的新计划 ID 保存本次页面内规则初值，不能注入其他计划。
- 发布成功后清除对应初值。取消发布保留后端 DRAFT 计划；未发布规则暂存于当前页面会话，刷新页面会丢失，未增加服务端规则草稿存储。
- 默认名称为「测试计划 001、002…」。创建成功后递增，失败不消耗编号；本机存储编号，同时避开已加载计划中的相同编号。此功能只是测试便利项，不是全局唯一业务编号，多浏览器并发不作唯一性保证。
- 广告位固定默认 game-home-banner，不跟随名称编号变化，避免破坏广告位匹配。名称和广告位仍可手动修改。默认周期为创建时起 7 天。
- 生成草稿仍基于真实 provider/model/fallback 展示来源，保留降级、字段不匹配和模型费用告警。提示词 v4 约定 device 字段及中文说明；模型仍可能出错，不静默重命名旧 platform 字段。
- 精简页面副标题、重复操作解释及空条件组；保留 ALL / ANY / NONE 的明确分组、费用告警、未发布提示。生成说明折叠展示，用户不必读 JSON。
