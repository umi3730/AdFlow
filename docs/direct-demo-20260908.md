# Demo 默认直接进入工作台

默认关闭认证和注册，打开或刷新页面直接进入管理员工作台，不显示登录、注册、退出入口。顶栏显示 admin / 管理员，不再展示免登录模式警告条。首次加载仅显示“正在进入工作台”，不先展示登录表单。

```env
ADFLOW_AUTH_ENABLED=false
ADFLOW_REGISTRATION_ENABLED=false
```

后端使用已有的免认证模式，为请求注入 `local-dev` 管理员身份；前端读取 `auth/me` 的实际权限，不伪造用户或自动提交账号密码。进入演示模式时清除内存中的旧 token，避免旧登录状态影响页面。

没有为每个访客创建数据库或账户。计划、画像和统计仍使用原来的业务存储；已有注册账号和 `auth_users` 表保留，默认入口不依赖该表。之前的账号也一直共用同一张用户表，并非每位用户独立建库。

可选的 JWT / RBAC / 注册代码保留。显式开启认证后才显示登录页；还需显式开启注册才能创建账号，注册角色仍遵循 Demo 管理员策略。关闭认证意味着能访问此 Demo 的人都具有管理员操作权限，这是当前共享演示模式的预期行为。

## 验证

- 两个本机 API 均返回 `authEnabled=false`、管理员角色，注册入口返回 403。
- 新浏览器打开与刷新均直接进入总览，未发送登录、注册或 auth/options 请求，也未携带 Bearer token。
- 登录、注册、退出按钮不存在，管理员操作按钮可用，管理员审计查询无须账号。
- 配置与认证回归、前端测试、lint 和构建通过；未新增或回退数据库迁移。

证据：[浏览器验证](verification/direct-demo/browser.json)、[页面截图](verification/direct-demo/workspace.png)。
