# 投放期显示与筛选（2026-09-07）

## 已修复

原页面把后端 ACTIVE 状态全部显示和统计为「投放中」。ACTIVE 是持久化的发布状态，不能代替当前投放时间判断。

新增纯函数 campaignDisplayStatus，统一用于总览计数、计划列表及摘要、状态/中文搜索、模拟页可投放计划数量和规则弹窗。没有修改后端生命周期或用户的真实起止时间。

| 条件 | 显示 |
| --- | --- |
| 未发布草稿 | 草稿 |
| 已发布，当前时间小于 startAt | 待开始 |
| ACTIVE 且 startAt ≤ 当前时间 < endAt | 投放中 |
| 暂停且未到结束时间 | 已暂停 |
| 已发布/暂停且当前时间 ≥ endAt，或持久化 ENDED | 已结束 |
| 已发布计划日期缺失、无法解析或起止顺序错误 | 时间异常 |

页面共享一个时钟，在最近的开始/结束边界刷新显示，最长一分钟校正一次，页面回到前台时立即校正；不为更新显示轮询后端。初始水合前使用「检查中」，避免把浏览器未知时间当成有效投放。

列表增加起止日期，规则弹窗显示完整投放区间，明确使用北京时间。发布确认不再承诺「立即进入投放中」，而是按既有投放期生效。已到期的暂停计划禁用「恢复」；持久状态仍为 ACTIVE 的到期计划可「停用」，之后继续走原有编辑/删除规则。

## 验证

- 固定样例有三个 ACTIVE 计划，分别尚未开始、正在投放、已经结束：旧判断统计 3 个投放中，新判断正确统计 1 个。
- 边界包含 startAt，排除 endAt；覆盖暂停、草稿、异常日期、时区跨日、中文状态筛选以及不改写输入对象。
- 注入时钟验证开始边界自动更新、页面回到前台更新、无重复定时器及卸载清理。
- 原始测试输出见 [period-tests.txt](verification/campaign-period/period-tests.txt)。
- 浏览器检查实际计划列表、日期列和规则弹窗；没有修改现有计划来制造过期场景。全套前端 96 项测试、TypeScript、lint、构建通过。

## 本轮边界

这是前端显示与操作提示修复，使用浏览器当前时间；不改变服务端候选缓存或投放规则，也不承诺绕过候选缓存的配置传播延迟。手动延长期限、复制计划仍是后续功能，本轮不会自动续期。已有的后端候选分页修复仍需后续重启服务加载，本轮未重启后端。
