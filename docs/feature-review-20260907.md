# 功能检查与演示基线（2026-09-07）

本轮按实际代码检查功能可用性，同时增加新环境可直接使用、允许用户删除的演示数据。不是性能压测，不生成历史曝光或性能数字。

## 本轮处理

- 自动安装一套演示计划、素材、命中/排除/未命中画像；初始化及删除规则见 [演示数据](demo-data.md)。
- 模拟页新增「载入演示用例」：只读取已有画像，设置少量固定轮次，不创建、不修复被删的数据，不自动发请求。
- 决策调试回传使用每次决策、每种事件稳定的 eventId；同步防止双击和并行提交，曝光成功后才开放点击与转化，成功后不重复回传，失败可用原 ID 重试。新决策/用户/广告位不沿用旧状态。
- CI 改为运行所有前端 `tests/*.test.mjs`，避免新增测试没有进入流水线。
- 后续已修复超过 100 条候选遗漏：ID 游标分页和按页批量素材读取，见 [候选读取修复](candidate-pagination-20260907.md)。
- 后续已修复投放期显示和筛选：按开始/结束时间派生状态、自动更新，见 [投放期显示](campaign-period-display-20260907.md)。
