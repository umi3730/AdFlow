# 前端鉴权与运行模式

最新更新：Demo 默认免登录进入管理员工作台，隐藏登录、注册与退出入口，见 [免登录模式](direct-demo-20260908.md)。下文保留历史认证方案说明。

## 本地使用

### 2026-09-04 后续调整：本机默认 admin

用户要求减少反复登录：`web/.env.local` 开启 `NEXT_PUBLIC_ADFLOW_DEMO_AUTO_LOGIN=true`。仅当页面和 API 均是 loopback HTTP(S) 地址、用户未主动退出时，首次 401 后尝试内置本机 admin 的普通密码登录，再请求 auth/me 验证身份；不绕过 JWT，也没有新增免鉴权管理员接口。公网页面或远程 API 不执行自动登录。自定义账号导致自动登录失败时保留手动表单，不循环重试。

退出会在当前标签页 sessionStorage 记录一个暂停自动登录的布尔偏好；不存密码或 Token。手动登录其他账号保持暂停，手动登录 admin 成功则恢复下一次刷新时自动登录。登录页不放主题图片，也不再展示 Token 存储说明。

以下“刷新需重新登录”描述适用于自动登录关闭、主动退出或其他账号的手动模式；本机默认 admin 模式会自动完成这一步。

- 本地启动配置启用 `ADFLOW_AUTH_ENABLED=true`，监听 `127.0.0.1:18080`；不对外暴露演示账号。
- 登录入口由 `/v1/auth/me` 的真实响应控制：401 显示登录页，免鉴权模式显示明确警告，连接错误显示重试而不是伪登录。
- 当前 local/test 的内置演示账号为 admin / adflow-admin、operator / adflow-operator、viewer / adflow-viewer。它们仅供本机测试；正式部署必须配置自己的用户密码哈希、JWT 密钥和 HTTPS。
- Token 仅存当前页面的内存，每次 API 请求自动附带 Bearer；刷新要重新登录，过期或受保护接口返回 401 退回登录页。403 保持登录并提示无权限。旧请求的 401 不会清除后来登录的新会话。
- 退出清除本页会话并卸载工作台（用户池模拟停止）。当前没有服务器端 Token 撤销、refresh token 或跨标签页会话同步；已签发 JWT 仍可能在服务端有效至其过期，不宣称生产级完整账号体系。
- 实际鉴权始终由 Go 中间件实施，隐藏按钮不是安全边界；前端权限与后端角色策略保持一致。

## 角色

- viewer：浏览计划、素材、画像、统计、运行态，不能创建/修改数据或发起决策。
- operator：可创建计划草稿、维护素材和画像、暂停/恢复、发起决策、使用 Agent；不能发布规则、删除资源、运行用户池模拟或重放死信。
- admin：允许上述管理操作。发布仍要人工确认。
- 顶栏显示接口返回的真实用户名与角色，不再使用固定 ZH 头像。WebMCP 创建计划工具只向具备运营权限的会话注册。

## 运行态

`GET /v1/operations/mode` 返回当前实际装配的 eventTransport / outboxEnabled（受 JWT 保护），不是 Kafka 连通性探测。

- sync：明确显示同步事件处理，不展示无意义的 0 积压/死信。
- kafka：展示 Outbox 和 Lag；没有分区采样显示未知，不等同于 Lag=0。
- 请求失败/加载中：显示未知值而不是健康状态。当前没有自动启动 Kafka 或 MySQL。

## 验证与范围

前端覆盖角色层级、Token 过期、401/403 区别、旧响应隔离、登录请求不带旧 Token、内存存储、登录边界与模式显示。后端覆盖 sync/kafka 模式响应及既有 JWT/RBAC 测试。重启前提仍是本地内存数据可清空；不迁移或伪造历史统计。

独立接口脚本在鉴权开启后也必须提供 Token；旧 k6 负载脚本尚未接登录，不能直接拿免鉴权时的启动方式运行。

本次验收：67 项前端测试、Go 全包串行测试、vet、类型检查与生产构建通过。`tests/frontend-auth-smoke.mjs` 在本机 JWT 开启后验证三种角色、未登录 401、越权 403、运营创建/管理员发布/删除及同步运行模式。验收计划仅由脚本创建并软删除，历史记录保留。未执行浏览器点击验收。

当前服务已按优化阶段授权重启并开启 JWT；之前未持久化的临时计划、画像和统计随重启清空，没有恢复历史数据。

补充回归发现：旧用户池验收脚本在清理时使用原始 fetch 读取计划，漏带 JWT，误将未授权响应当成计划，导致未暂停就删除而触发 409。已改为统一鉴权 API 读取计划，再暂停/清理脚本自己的数据；实际决策、曝光、点击、转化回传均已成功。这是测试脚本适配问题，不是通过放宽后端权限修复。
