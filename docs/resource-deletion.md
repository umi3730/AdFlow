- 计划必须先暂停，素材必须先禁用。按钮会显示原因，而不是无说明地禁用。

## 删除语义

禁用不等于删除：素材现在支持 `POST /v1/campaigns/{id}/creatives/{creativeId}/enable`，仅 DISABLED → ACTIVE，可反复启用/禁用；计划继续使用原有暂停/恢复。已删除资源不能重新启用，启用素材也不会自动恢复计划。

- `DELETE /v1/campaigns/{id}`：DRAFT / PAUSED / ENDED 变为内部 DELETED 状态，保留计划行、历史版本、素材、统计与事件。普通列表和详情不可见；不提供恢复接口。
- `DELETE /v1/campaigns/{id}/creatives/{creativeId}`：仅允许 DISABLED 素材软删除；校验所属计划，保留历史引用。
- 上述两类再次删除返回 404。保存仍受 revision 乐观锁保护，并发发布/恢复不能通过旧 revision 复活删除记录。
- `DELETE /v1/profiles/{userId}`：删除当前模拟画像，重复执行返回 204；不删除历史决策、预占、事件。同名画像可重新创建，删除前的属性无自动恢复功能。
- 开启认证时三类删除均要求 admin；本地无认证模式仍使用现有 local-dev 管理员。删除成功和失败进入既有审计中间件，审计仍是现有非事务耦合设计。
- MySQL 的 status 列原本是 VARCHAR，无需新迁移。原始数据保留不等于已经实现回收站。

## 缓存边界

- 候选快照缓存仍有 TTL（默认 5 秒），暂停、禁用和删除不是对在途请求的强制撤销，既有预占/事件不清理。
- 画像缓存适配器在源删除后失效对应 Redis key，用同一进程的 key lock 避免与回填/写入交叉。缓存失效错误会返回失败，源可能已经删除；重复删除可重试清理。
- 多实例缓存回填与 Redis 故障期间仍沿用现有最终一致性边界，未宣称全局立即失效。
