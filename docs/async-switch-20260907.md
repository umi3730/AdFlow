## 真实依赖发现及修复

首次真实测试发现，新结算任务使用 MySQL 默认北京时间，而租约查询使用 UTC，任务无法立即领取。`loc=UTC` 只控制 Go 驱动对时间的转换，不会改变 MySQL 会话时区。

已将应用连接的会话时区和驱动时间统一为 UTC；结算任务显式使用数据库 UTC 时间设置初始重试时间。Windows 与 WSL 时钟还存在约一秒偏差，因此 Outbox 领取也读取数据库时间，与结算完成时间采用同一个时钟。

失败记录和修复后的真实通过记录均保留在 `verification/async-switch`，没有用模拟结果替代真实基础设施验收。

## 下次启动

在项目根目录执行：

```powershell
./ops/native/start-components.ps1
./ops/native/start-api.ps1 -Port 18080
```

若继续使用 3001 预览，再启动 `./ops/native/start-api.ps1 -Port 18081`。启动脚本读取本机 `.env` 并构建新版，每个进程使用独立日志/二进制文件；端口已占用时会报错，不会自行杀掉其他进程。前端仍按原来的开发命令启动。

之后新增数据库迁移时，需加载本机 `.env` 的配置再执行项目迁移命令；API 启动脚本本身不自动执行数据库迁移。
